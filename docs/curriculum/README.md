## 4. 순서 위반 검사 (참고용 — v3 결과, 재실행하지 않음)

**이 지표는 포화됐다.** v1(21건, 고정 10x10 틀 안에서의 위반) -> v2(38건, 주제 우선 재편 직후) ->
v3(38건, 챕터 순서 재배치 후)로 이어지는 동안, 총 위반 건수는 챕터를 아무리 재배치해도 0으로
수렴하지 않았다. 이유: 금리·투자·주식·부동산·자산처럼 뉴스에도 흔하고 콘텐츠 카드로도 만든
일상 단어가 많아질수록, 어떤 카드의 설명문이든 다른 카드의 제목 문자열을 스치듯 포함할 확률이
올라간다. 즉 이 시점부터는 "순서가 잘못됐는가"가 아니라 "흔한 경제 단어를 몇 개나 카드로
등록했는가"를 재는 지표가 됐다. 앞으로 콘텐츠가 100개, 200개로 늘어날수록 이 문자열 검사의
위반 건수는 구조와 무관하게 계속 늘어날 것으로 예상되므로, 챕터 순서를 판단하는 용도로는
더 이상 쓰지 않는다. 아래는 v3에서 마지막으로 실행한 결과를 그대로 옮긴 것이다(금리를 1챕터로
옮기기 전 기준이라 "예금->금리", "신용등급->금리" 등 일부는 재실행하면 사라질 것으로 보이지만,
위 이유로 재실행하지 않았다).

> 검사 방법: v1/v2와 동일 — 기존 한잎의 description+whyImportant 본문에서 뒤 챕터 항목의 제목이
> 문자열로 등장하는지 확인(2글자 이하는 경계 검사). 신규 개념은 본문이 없어 검사 대상에서 제외.
