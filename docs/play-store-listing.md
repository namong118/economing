## 3. 전체 설명 (4000자 이내)

```
경제 뉴스를 열었다가 세 줄 만에 닫아본 적 있나요?

기준금리, 무역수지, 장단기 금리 역전... 경제 뉴스는 이미 아는 사람을 전제로 쓰여 있습니다.
유튜브로 배워보려 해도 재미있는 다른 영상에 밀려 며칠 안에 흐지부지되고,
주식·투자·부동산·연금·절세, 뭐부터 시작해야 할지 알려주는 곳도 없습니다.

ECONOMING(economy + -ing, "경제를 배워가는 중")은
20~30대 사회초년생과 경제 초보자를 위해 만든 경제 학습 앱입니다.
주식 종목을 추천하지 않습니다. 스스로 판단할 수 있게 되는 것이 목표입니다.

▶ AI가 수준을 진단합니다
10개 문항으로 경제 지식 수준을 5단계로 나눠, 나에게 맞는 설명 깊이를 찾습니다.

▶ 사람이 검증한 13챕터 112개 커리큘럼 — 경제한잎
실제 경제 뉴스 420건을 분석해 어떤 용어가 얼마나 쓰이는지 측정하고,
그 데이터를 근거로 112개 용어와 순서를 정했습니다.
일상에 가까운 것부터 먼 것 순으로, 하루 한 개씩 부담 없이.
설명·인포그래픽·퀴즈가 모두 포함되어 있습니다.

▶ 오늘의 경제를 읽습니다
- 뉴스: 실시간 경제 뉴스를 AI가 초보자 관점으로 다시 씁니다. 3문장 요약, 핵심 3가지,
  어려운 용어는 따로 뽑아 설명을 붙입니다.
- 지표: 코스피·코스닥·환율·기준금리 등 11종 지표를 한국은행 ECOS·통계청 KOSIS
  공공데이터로 직접 가져와 "오늘 이 숫자가 어떤 의미인지" 그 근거까지 화면에 그대로
  보여줍니다. "높다/낮다"를 함부로 말하지 않고, 최근 10년 이력 등 기준을 밝힙니다.

▶ 막히면 AI 코치 노밍에게 다시 묻습니다
커리큘럼 밖의 질문, 뉴스에 나온 낯선 단어, "그래서 내가 뭘 해야 하죠?" 같은 물음도
받아줍니다. 모든 답변 끝에는 "오늘 5분 안에 할 수 있는 한 가지"가 붙습니다.

▶ 배운 것을 남깁니다
- 나만의 경제 사전: 막혔던 용어를 버튼 하나로 저장. 검색해서 찾는 사전이 아니라
  내가 실제로 궁금했던 단어가 쌓이는 사전입니다.
- 경제일기: 오늘 배운 것, 오늘의 소비, 아직 궁금한 것 등 6개 항목으로
  경제 지식을 내 삶과 연결합니다.

▶ 경제 자립 진단 + AI 개인화 로드맵
비상금·저축·부채·연금·보험·투자·절세 등 10개 영역을 진단하고,
"네이버에서 'ISA 계좌' 검색 → 나이 확인 → 유형 메모하기 (5분)"처럼
앱 이름과 클릭 순서, 소요 시간까지 구체적인 실행 계획을 받습니다.

경제학자가 되기 위한 앱이 아닙니다.
내 돈에 대해 스스로 판단할 수 있게 되는 것, 그것이 ECONOMING의 전부입니다.

모든 기능은 무료로 제공됩니다.
```

**글자 수**: 약 1,050자 (4,000자 한도의 여유 큼 — 필요하면 스크린샷 순서에 맞춰 기능 설명 확장 가능)

## 6. 데이터 안전성(Data safety) 양식 답변 초안

코드 기준(`supabase/schema.sql`, `authService.js`, edge functions) 실제 수집 데이터만 정리.
**주의**: 아래는 초안이며, Play 정책상 "제3자 공유"의 정확한 판단(단순 처리자 vs 공유)은
최종적으로 사용자가 Upstage/Supabase와의 계약 관계를 보고 판단해야 합니다.

### 수집 여부
**예, 데이터를 수집합니다.**

### 수집 데이터 항목

| 카테고리 | 세부 항목 | 근거 | 필수/선택 | 목적 |
|---|---|---|---|---|
| 개인 정보 | 이름(닉네임) | `profiles.nickname` | 필수 | 앱 기능 |
| 개인 정보 | 이메일 주소 | `profiles.email` | 필수 | 계정 관리, 앱 기능 |
| 개인 정보 | 사용자 ID | Supabase auth UID | 필수 | 앱 기능 |
| 사진 | 프로필 사진 | `profiles.avatar_url` (구글/카카오 프로필 이미지 URL) | 선택 | 앱 기능 |
| 재무 정보 | 소득 구간, 재무 목표, 투자 경험, 직업 | `profiles.income_range` 등 온보딩 응답 | 선택 | 앱 기능(개인화 로드맵 생성) |
| 앱 활동 | 학습 진도, 앱 내 상호작용, 검색 기록(경제사전) | `roadmap_progress`, `vocabulary` | 필수 | 앱 기능 |
| 메시지 | AI 코치와의 대화 내용 | `coach_conversations` | 선택 | 앱 기능 |
| 사용자 제작 콘텐츠 | 경제일기 내용 | `economic_journals` | 선택 | 앱 기능 |

### 수집하지 않는 항목
- 위치 정보, 연락처, 사진(갤러리 접근), 오디오/동영상, 기기 ID·광고 ID, 결제 정보 — 전부 미수집
  (권한이 `INTERNET` 하나뿐인 것과 일치)

### 데이터 공유(제3자)
- **Google / Kakao**: 로그인(OAuth)에만 사용. 앱이 이 두 서비스로 데이터를 "공유"하는 게
  아니라, 사용자가 그 계정으로 로그인하는 표준 인증 흐름.
- **Upstage(Solar AI, `api.upstage.ai`)**: 코치 대화·로드맵 생성·뉴스 재작성을 위해
  질문/온보딩 응답 등이 전송됨. [ ] Upstage와의 데이터 처리 계약(광고·자체 목적 사용 금지
  조항 여부)을 확인해 "제3자 공유"로 표시할지, "서비스 제공자(처리자)"로 볼지 결정 필요.
- **Supabase**: 백엔드 인프라(Auth/DB/Edge Functions) — 일반적으로 개발자를 대신해
  데이터를 처리하는 서비스 제공자로, Play 정책상 별도의 "제3자 공유"로 표시하지 않아도
  되는 경우가 많음(자체 목적 이용이 없는 경우). [ ] Supabase와의 계약 확인 권장.
- **광고/애널리틱스 SDK 없음** — `package.json`에 Firebase, AdMob, 애널리틱스 SDK
  일체 없음. 이 부분은 "아니요"로 명확히 답변 가능.

### 보안 관행
- [x] 전송 중 암호화(HTTPS/TLS) — Supabase, Upstage 모두 HTTPS
- [x] "사용자가 데이터 삭제를 요청할 수 있나요?" → **예, 앱 내에서 가능.**
  내 성장 탭 하단 "회원 탈퇴" → Edge Function(`delete-account`)이 `auth.admin.deleteUser` 호출 →
  `ON DELETE CASCADE`로 모든 관련 데이터(프로필/사전/일기/대화/진도) 즉시 삭제. 실기기에서 검증 완료(2026-08-18).
  Play Console 양식에서 "인앱에서 삭제 가능"으로 답변하면 됨.
